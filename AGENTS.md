# Règles du projet

- Utiliser Laravel 13 et Blade pour le rendu côté serveur.
- Réserver Vue 3 aux composants interactifs.
- Utiliser Tailwind CSS 4 avec une approche mobile-first.
- Ajouter et exécuter les tests pertinents pour toute modification.
- Ne jamais versionner de données sensibles (`.env`, secrets, jetons, clés ou identifiants).
